# FlashCard AI

Вебзастосунок для автоматичної генерації навчальних флеш-карток із конспектів та статей українською мовою за допомогою локальної LLM (`llama-server`), перекладача (`MyMemoryTranslator`), FastAPI-бекенду та React + TypeScript фронтенду.

---

## Структура проєкту

```text
app/
├── backend/                  # FastAPI + SQLAlchemy + SQLite
│   ├── main.py               # Точка входу, маршрути API та SSE-стрімінг
│   ├── database.py           # Підключення до SQLite (flashcards.db)
│   ├── models/               # ORM-моделі (User, Desk, Card)
│   └── service/
│       ├── auth.py           # Реєстрація, логін, JWT-токени
│       ├── crud.py           # Збереження, отримання та видалення колод
│       └── generator.py      # Пайплайн генерації, батчинг, валідація тексту
├── frontend/                 # React + TypeScript + Vite
│   ├── src/
│   │   ├── api/client.ts     # Клієнт API + парсер SSE-потоку
│   │   ├── components/       # AuthForm, GeneratorPanel, DeckList, StudyViewer
│   │   ├── App.tsx
│   │   └── types.ts
│   └── package.json
└── README.md
```

## Покроковий запуск проєкту

Для повної роботи потрібно запустити **3 процеси** у різних терміналах: `llama-server`, `backend` та `frontend`.

### 1. Запуск локальної LLM (`llama-server`)

Бекенд очікує OpenAI-сумісний сервер `llama-server` на **`http://127.0.0.1:9931`**.

```powershell
llama-server -m шлях\до\вашої\моделі.gguf --host 127.0.0.1 --port 9931
```

> Бекенд автоматично визначає назву завантаженої моделі через `GET http://127.0.0.1:9931/v1/models`.

---

### 2. Налаштування та запуск бекенду (`backend/`)

Перейдіть у папку `backend`:

```powershell
cd backend
```

*(Рекомендовано)* Створіть та активуйте віртуальне середовище:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Встановіть необхідні Python-залежності:

```powershell
pip install fastapi uvicorn sqlalchemy requests deep-translator pyjwt "passlib[bcrypt]" python-multipart pydantic
```

Запустіть FastAPI-сервер на порту **8000**:

```powershell
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Після запуску:
- API доступне за адресою `http://127.0.0.1:8000`
- Інтерактивна документація Swagger: `http://127.0.0.1:8000/docs`
- База даних SQLite `flashcards.db` створюється автоматично при старті.

---

### 3. Налаштування та запуск фронтенду (`frontend/`)

Відкрийте новий термінал і перейдіть у папку `frontend`:

```powershell
cd frontend
```

Встановіть npm-залежності (потрібно виконати один раз):

```powershell
npm install
```

Запустіть dev-сервер Vite:

```powershell
npm run dev
```

Фронтенд відкриється за адресою: **`http://localhost:5173`**

*(Опціонально)* Якщо бекенд запущено на іншій адресі або порту, створіть файл `frontend/.env` і вкажіть:

```env
VITE_API_URL=http://127.0.0.1:8000
```

Для перевірки TypeScript та production-збірки:

```powershell
npm run build
```

## Основні можливості

- **Авторизація (JWT)**: реєстрація та вхід користувача, привʼязка колод до акаунту.
- **Обмеження вхідного тексту до 500 слів** та **батчева обробка**:
  - На фронтенді показується лічильник `X / 500 слів`.
  - На бекенді текст автоматично розбивається на пачки до `90` слів / `450` символів для стабільного перекладу та генерації малою моделлю.
- **Обовʼязковий ліміт токенів (`max_tokens`)**: регулюється від `128` до `4096` (за замовчуванням `1024`), щоб мала модель не зациклювалася.
- **Стрімінг (SSE)**: у реальному часі показуються етапи (`Підключення` → `Переклад` → `Генерація` → `Парсинг` → `Збереження`), поточна пачка та живий вивід JSON від моделі, з можливістю зупинити генерацію.
- **Захист від сміттєвого вводу**: бекенд відсіює випадковий набір літер, суцільні символи або повтори до відправки запиту на LLM (але пропускає нормальні технічні тексти, зокрема з хешами).
- **Режим вивчення карток**: 3D-перегортання по кліку або клавіші `Space`, навігація `←` / `→`, перемішування та перегляд списком.

## Основні API-ендпоінти

| Метод | Шлях | Опис |
| :--- | :--- | :--- |
| `GET` | `/health` | Стан бекенду та доступність `llama-server` (`:9931`) |
| `POST` | `/register` | Реєстрація користувача (`username`, `passw` як query-параметри) |
| `POST` | `/login` | Вхід (OAuth2 form-data), повертає JWT `access_token` |
| `POST` | `/generate` | Синхронна генерація та збереження колоди |
| `POST` | `/generate/stream` | Потокова генерація колоди (SSE `text/event-stream`) |
| `GET` | `/desks` | Отримання всіх колод поточного користувача |
| `DELETE` | `/desks/{desk_id}` | Видалення колоди |

## Часті помилки та як їх вирішити

- **«Бекенд-сервер не запущено або недоступний»** — переконайтеся, що у папці `backend/` запущено `uvicorn main:app --reload --host 127.0.0.1 --port 8000`.
- **«LLM-сервер (llama-server) не запущено на порту 9931»** — запустіть `llama-server` із флагом `--port 9931` та перевірте індикатор статусу у верхній панелі інтерфейсу.
- **«Сервіс MyMemory тимчасово обмежив запити»** — зачекайте 10–15 секунд і повторіть запит.
- **«Модель повернула некоректну відповідь» / обірваний JSON** — збільште `max_tokens` (наприклад, до `1536` або `2048`).
